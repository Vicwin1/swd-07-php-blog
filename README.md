# SWD Blog CMS

A PHP 8 and MySQL blog CMS for `http://localhost/swd/07-php-blog/`, designed to run from XAMPP.

## Features

- Public homepage with newest published posts and six-post pagination.
- Clean post and category URLs, full-text search, reading-time estimates, and related posts.
- Responsive post cards and readable article layout.
- Admin sign-in, dashboard, and category/post create, edit, list, filter, and delete tools.
- Post excerpts, publication status, author/category relations, and unique slugs.
- CSRF-protected admin mutations, prepared database queries, escaped output, and restricted image uploads.
- Command-line scripts to create the first admin and seed example posts.

## Setup with XAMPP

1. Place the project at `C:\xampp\htdocs\swd\07-php-blog`.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel. Ensure Apache has `mod_rewrite` enabled and `AllowOverride All` configured for this project directory.
3. Open `http://localhost/phpmyadmin/`, choose **Import**, select this project's `database.sql`, and run the import. This creates the `swd_blog` database and its tables.
4. If your local MySQL credentials differ from the defaults, configure the connection using environment variables:
   - `DB_HOST` (default `127.0.0.1`)
   - `DB_PORT` (default `3306`)
   - `DB_NAME` (default `swd_blog`)
   - `DB_USER` (default `root`)
   - `DB_PASSWORD` (default empty)
5. In Command Prompt or PowerShell, change to the project folder and create the first admin:

   ```text
   cd C:\xampp\htdocs\swd\07-php-blog
   C:\xampp\php\php.exe create-admin.php "Your Name" you@example.com
   ```

   The command prompts for a password (minimum 12 characters). It can instead be supplied via the `ADMIN_PASSWORD` environment variable.
6. Optionally add example content:

   ```text
   C:\xampp\php\php.exe seed.php
   ```

   Seeding requires an admin account, creates the Tutorials, News, and Career categories if missing, and skips seeded posts that already exist.
7. Visit `http://localhost/swd/07-php-blog/` for the public site or `http://localhost/swd/07-php-blog/admin/login.php` to manage content.

PHP needs the PDO MySQL, Fileinfo, iconv, and mbstring extensions enabled. The `app/` directory denies web access. Uploads are limited to 2 MB and accepted only when their detected content is JPEG, PNG, or WebP; filenames are generated by the application.

### Existing database upgrade

If your `posts` table predates the excerpt field, run this once in phpMyAdmin's SQL tab:

```sql
ALTER TABLE posts ADD COLUMN excerpt TEXT NULL AFTER slug;
```

## Export the database from phpMyAdmin

To save a database export as this project's `database.sql`:

1. Open `http://localhost/phpmyadmin/` and select the `swd_blog` database.
2. Choose **Export**, select **Custom** if you want to confirm the tables and options (or **Quick** for defaults), and choose **SQL** as the format.
3. Click **Go** and save/download the exported SQL file as `database.sql` in the project folder.

The export contains the database's current structure and, depending on the export options, its data. Back up the existing `database.sql` first if you want to keep the clean schema-only setup file.

## Folder structure

```text
07-php-blog/
├── admin/
│   ├── categories/       # Category CRUD
│   ├── posts/            # Post CRUD and status filter
│   ├── index.php         # Admin dashboard
│   ├── layout.php        # Shared admin layout and upload helpers
│   ├── login.php
│   └── logout.php
├── app/                  # Private bootstrap, DB, auth, CSRF, helpers
├── assets/
│   └── style.css
├── uploads/              # Validated cover images; PHP execution disabled
├── category.php
├── create-admin.php      # CLI-only first-admin setup
├── database.sql
├── index.php
├── post.php
├── search.php
└── seed.php              # CLI-only sample content
```

The root `.htaccess` provides `/post/{slug}`, `/category/{slug}`, and `/search` routes. `app/.htaccess` denies direct requests to application files, while `uploads/.htaccess` disables script handling in the upload directory.
